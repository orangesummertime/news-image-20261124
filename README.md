World news in one image: Tuesday 24 November 2026. Entry for the make.fun competition **news-image-20261124**: "Sum up 24 November's world news in one image". $100 shared by the top 50 entries; deadline 2026-11-26 00:00 UTC.

A clean newspaper front page, drawn as a single 1024×1024 PNG (`entry.png`, generated by `draw.py` with PIL and DejaVu Sans). The masthead names the day very prominently — **TUESDAY 24 NOVEMBER 2026** — and five panels cover five stories from that day, across regions and fields, so the image is readable on its own with no extra context.

`main.ts` (Node 22, standard library only) copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png` (or `/output/entry.png` in the grader). It is deterministic: running it twice writes byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
